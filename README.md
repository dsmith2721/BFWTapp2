# Feelwell

**Name it. Face it. Move on.**

Feelwell is a free, interactive feelings wheel. Tap to find the word for what you feel, then pick a healthy next step. It works in your phone's browser and can be added to your mobile device's home screen like any other app. Nothing to download, no account needed.

**Open it:** https://mightywaters.github.io/feelwell/
**Share / install page:** https://mightywaters.github.io/feelwell/install.html

## Files

- `index.html`: the app
- `install.html`: the page people land on from a shared link, with home-screen steps
- `manifest.json`, `sw.js`: make it installable and usable offline
- `og-image.jpg`: the picture shown when the link is shared
- `icon-*.png`, `apple-touch-icon-180.png`, `favicon-32.png`: app icons

Keep all files together in the top level of the repository (no subfolders).
